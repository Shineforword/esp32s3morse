# 工程结构

本仓库是 ESP-IDF 工程，目标芯片 **ESP32-S3**。固件开 SoftAP（可选再以 STA 进局域网），手机浏览器访问板载网页，控制板载 WS2812、无源蜂鸣器、ST7789 屏，并可向局域网 Mosquitto 发一条测试 MQTT。

工程名：`esp32s3_morse`（根目录 `CMakeLists.txt`）。`main/` 只做启动胶水，业务按域拆在 `components/`。

## 学习示例开关

`idf.py menuconfig` → **学习示例开关**：摩斯 / 简谱 / LCD / Tank / MQTT 可自由组合。关掉的功能不进固件，首页也不显示对应卡片。默认全开。说明见 [调试编译烧录.md](调试编译烧录.md)。

## 组件职责

| 组件 | 公开头文件 | 职责 |
|------|------------|------|
| `board` | `app_config.h`、`board_led.h` | GPIO/时序/屏参/MQTT 宏；创建 WS2812 |
| `wifi` | `wifi_softap.h` | SoftAP；可选 STA（`MQTT_STA_WIFI_SSID`） |
| `mqtt_lan` | `mqtt_lan.h` | STA 获 IP 后向 broker 发测试消息 |
| `morse` | `morse_decode.h`、`morse_player.h` | 摩斯解码；灯/蜂鸣器同步播放 |
| `buzzer` | `morse_buzzer.h` | LEDC、简谱、《两只老虎》 |
| `lcd` | `lcd_st7789.h` | SPI 屏、Hello/Tank/摩斯画面；`tank_rgb565.c` |
| `web` | `morse_http.h` | 内嵌页面 + REST API |

热点名在 `wifi_softap.h`；灯/蜂鸣器/屏/MQTT 在 `app_config.h`。

## 启动顺序

`main/main.c` 中 `app_main`：

1. **NVS**
2. **`board_led_init`** → WS2812
3. **`morse_player_init`**
4. **`wifi_softap_init`**
5. **`morse_http_start`**

LCD 首次相关 API 时懒初始化。

## 网页与 API

手机连热点后访问 `http://192.168.4.1/`。

| 方法 | 路径 | 作用 |
|------|------|------|
| GET | `/` | 功能卡片首页 |
| GET | `/morse` | 摩斯输入 |
| GET | `/music` | 简谱 /《两只老虎》 |
| GET | `/lcd` | 屏幕 Hello |
| GET | `/tank` | 全屏 Tank |
| GET | `/mqtt` | MQTT 测试页 |
| POST | `/api/preview` | 单点/划闪灯 |
| POST | `/api/decode` | 只解码 |
| POST | `/api/play` | 整段播放 |
| POST | `/api/tone` | `{"note":1}`～`7` |
| POST | `/api/play_twotigers` | 整曲 |
| POST | `/api/lcd_hello` | Hello World |
| POST | `/api/lcd_tank` | 全屏 tank |
| POST | `/api/mqtt_hello` | MQTT 测试 |

摩斯约定：字母间 `/`，单词间 `//`。队列长度见 `MORSE_PLAY_QUEUE_LEN`。

## 换全屏图

```bash
python3 tools/gen_tank_rgb565.py
```

默认读 `assets/tank.png`，写出 `components/lcd/tank_rgb565.c`，再重新编译烧录。

## 数据流

```
手机浏览器
    │  HTTP (AP)
    ▼
web (morse_http)
    ├─ decode ──► morse
    ├─ preview/play ──► morse_player ──► board WS2812
    │                      └── 同步 ──► buzzer
    ├─ tone / 两只老虎 ──► buzzer
    ├─ lcd_* ──► lcd
    └─ mqtt_hello ──► mqtt_lan ──► Mosquitto
                         ▲
                      wifi (STA)
```
