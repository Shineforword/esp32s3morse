# 工程结构

本仓库是 ESP-IDF 工程，目标芯片 **ESP32-S3**。固件开 SoftAP（可选再以 STA 进局域网），手机浏览器访问板载网页，控制板载 WS2812、无源蜂鸣器、ST7789 屏，并可向局域网 Mosquitto 发一条测试 MQTT。

CMake 工程名仍为 `hello_world`（根目录 `CMakeLists.txt`），业务代码全部在 `main/`。

## 目录一览

```
ESP32-S3/
├── CMakeLists.txt              工程入口：引入 IDF、project(hello_world)
├── sdkconfig                   menuconfig 结果（芯片、Flash、分区、httpd 等）
├── partitions_4mb.csv          自定义分区：factory 应用区 4MB
├── main/                       本工程唯一业务组件
├── managed_components/         组件管理器拉取的依赖（led_strip）
├── tools/                      离线资源生成脚本
├── build/                      CMake/Ninja 产物（gitignore，勿提交）
├── .clangd                     clangd 过滤 GCC 专有参数
├── .gitignore
├── docs/                       本目录
└── README.md                   功能与接线总览
```

不进 Git 的常见目录：`build/`、`.cache/`（clangd 索引）、`.vscode/`、`sdkconfig.old`。

## `main/` 模块

`main/CMakeLists.txt` 把下列 `.c` 编进 `main` 组件，并声明对 IDF 组件的依赖：`led_strip`、`driver`、`esp_http_server`、`esp_wifi`、`esp_netif`、`nvs_flash`、`esp_event`、`esp_lcd`、`heap`、`mqtt`。

| 文件 | 职责 |
|------|------|
| `app_config.h` | GPIO、亮度、摩斯时序、LCD、MQTT 等可调宏（改参数优先只改这里） |
| `main.c` | `app_main`：NVS → WS2812 → 播放器 → SoftAP → HTTP |
| `wifi_softap.c/.h` | SoftAP 热点；若配置了 STA SSID 则走 APSTA |
| `morse_http.c/.h` | 内嵌 HTML 页面 + `/api/*` JSON |
| `morse_player.c/.h` | WS2812 预览/整段播放；独立 FreeRTOS 任务 + 队列 |
| `morse_buzzer.c/.h` | 无源蜂鸣器 LEDC PWM；与灯互斥；简谱 /《两只老虎》 |
| `morse_decode.c/.h` | 摩斯串 → 可读文字（纯逻辑） |
| `lcd_st7789.c/.h` | ST7789 SPI 初始化、Hello、Tank、摩斯实时画面 |
| `font8x8_basic.c` | 8×8 点阵字模，给 LCD 文字用 |
| `mqtt_lan.c/.h` | STA 获 IP 后向 broker 发一条测试消息 |
| `tank.png` | 全屏图源文件 |
| `tank_rgb565.c` | 由脚本生成的 240×280 RGB565 数组，勿手改大数组 |
| `idf_component.yml` | 声明依赖 `espressif/led_strip` |

热点名、密码在 `wifi_softap.h`（`WIFI_SSID` / `WIFI_PASS`）。灯、蜂鸣器、屏、MQTT 在 `app_config.h`。

## 启动顺序

`app_main` 顺序不能随意对调：

1. **NVS**：Wi‑Fi 栈依赖；分区异常时擦除再 init。
2. **WS2812**：RMT 创建灯带句柄（默认 GPIO48，1 颗）。
3. **`morse_player_init`**：队列、互斥锁、播放任务（依赖灯带句柄）。
4. **`wifi_softap_init`**：开热点；若 `MQTT_STA_WIFI_SSID` 非空则同时 STA。
5. **`morse_http_start`**：HTTP 依赖网络已起。

LCD 不在启动时初始化，第一次 `POST /api/lcd_hello` 或 `/api/lcd_tank`（以及相关屏刷新）才 `lcd_st7789_ensure_init()`。

## 网页与 API

手机连热点后访问 `http://192.168.4.1/`（网关以串口日志为准）。服务为明文 HTTP。

| 方法 | 路径 | 作用 |
|------|------|------|
| GET | `/` | 功能卡片首页 |
| GET | `/morse` | 摩斯输入 |
| GET | `/music` | 简谱 1～7、《两只老虎》 |
| GET | `/lcd` | 屏幕 Hello |
| GET | `/tank` | 全屏 Tank |
| GET | `/mqtt` | MQTT 测试页 |
| POST | `/api/preview` | 单点/划闪灯 |
| POST | `/api/decode` | 只解码不播放 |
| POST | `/api/play` | 整段入队播放，返回解码 |
| POST | `/api/tone` | `{"note":1}`～`7` |
| POST | `/api/play_twotigers` | 播整曲 |
| POST | `/api/lcd_hello` | 屏上 Hello World |
| POST | `/api/lcd_tank` | 全屏 tank |
| POST | `/api/mqtt_hello` | 向 Mosquitto 发测试消息 |

摩斯串约定：字母之间 `/`，单词之间 `//`。播放队列长度见 `MORSE_PLAY_QUEUE_LEN`（默认 4），满则接口返回 `queue full`。

## 硬件相关配置落点

- **WS2812**：`MORSE_LED_GPIO`（默认 48）。
- **蜂鸣器**：`MORSE_BUZZER_GPIO`（默认 4；`-1` 关闭）。
- **ST7789**：`LCD_PIN_*`，默认 SCL=12、SDA=11、RES=14、DC=13、CS=10；BLK 常接 3.3V（`LCD_PIN_BLK_GPIO = -1`）。分辨率 240×280，行偏移 `LCD_GAP_Y = 20`。
- **热点**：`wifi_softap.h`。
- **STA / MQTT**：`app_config.h` 中 `MQTT_STA_*`、`MQTT_BROKER_URI` 等。SSID 为空则不连路由器，MQTT 页会失败。

引脚勿与灯 48、蜂鸣器 4 冲突。接线细节见根目录 `README.md`。

## 构建与分区

- 芯片：`sdkconfig` 中 `CONFIG_IDF_TARGET=esp32s3`。
- Flash：16MB，DIO，80MHz。
- 分区表：`partitions_4mb.csv`（`nvs` + `phy_init` + `factory` 4MB），对应 `CONFIG_PARTITION_TABLE_CUSTOM`。
- HTTP：`CONFIG_HTTPD_MAX_REQ_HDR_LEN` / `CONFIG_HTTPD_MAX_URI_LEN` 已提到 2048，减轻手机浏览器 431。

```bash
python3 tools/gen_tank_rgb565.py
```

依赖 Pillow。生成结果覆盖 `main/tank_rgb565.c`，需重新编译烧录。

## 数据流（简图）

```
手机浏览器
    │  HTTP (AP: 192.168.4.1)
    ▼
morse_http  ──decode──► morse_decode
    │
    ├─ preview/play ──► morse_player ──► WS2812 (RMT)
    │                      └── 同步 ──► morse_buzzer (LEDC)
    ├─ tone / 两只老虎 ──► morse_buzzer
    ├─ lcd_hello / lcd_tank ──► lcd_st7789 (SPI)
    └─ mqtt_hello ──► mqtt_lan ──► 局域网 Mosquitto
                         ▲
                    wifi_softap (STA 获 IP)
```
